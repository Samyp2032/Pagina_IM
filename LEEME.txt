Archivos:
  index.html         estructura de la pagina
  style.css          estilos
  data.js            preguntas y respuestas (editalo aqui si cambias algo)
  app.js             logica del simulador
  generar_audios.py  crea la carpeta audio/ con las voces (es: em_alex, en: af_heart)
  .nojekyll          (vacio, necesario para GitHub Pages)

Pasos (PowerShell dentro de esta carpeta):
  pip install kokoro soundfile numpy
  python generar_audios.py
Si sale un error que menciona "espeak", instala espeak-ng (.msi):
  https://github.com/espeak-ng/espeak-ng/releases
Luego sube todo a GitHub, incluida la carpeta audio/.
